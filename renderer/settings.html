中继服务模式（把本机作为房间的私有中继）

本机内嵌 MQTT 中继（仅绑定 127.0.0.1），经 Cloudflare 隧道向房间成员开放。中继只转发密文 （端到端加密不受影响）；本机离线时成员自动回落公共中继。成员接入：把下方地址粘贴到 「网络 → MQTT broker」列表。
快速隧道零配置，但地址每次启动会变化；需要稳定地址：安装 cloudflared 后 执行一次 cloudflared tunnel login → cloudflared tunnel create <名字> → cloudflared tunnel route dns <名字> <你的域名>， 然后运行 cloudflared tunnel run --url http://127.0.0.1:<端口> <名字>，并把 wss://<你的域名> 填入下方"对外公布地址"。
